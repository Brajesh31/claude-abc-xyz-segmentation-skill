# ABC XYZ Segmentation Skill

A Claude skill for segmenting SKU portfolios by value (ABC) and demand variability (XYZ), building the 9-box matrix, and assigning planning policies to each segment.

## Repository contents

- `SKILL.md`: original skill instructions.

## Usage

Install this skill in the skills directory used by your Claude-compatible environment. Keep `SKILL.md` at the skill root.

Use it for ABC analysis, XYZ demand classification, SKU rationalisation, and inventory planning prioritisation.
